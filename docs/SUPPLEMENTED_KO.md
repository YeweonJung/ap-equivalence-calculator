# 보완 환산 결과

Excel 결과의 기존 Results, MedicationResults, Review, AuditTrail은 각 방법의 원래 결과를 유지합니다. 끝에 두 시트를 추가합니다.

- **보완합계**: 환자·날짜·기본 방법별 총합, 사용 방법, 보완 약물 수와 미환산 수입니다. 미환산 항목이 하나라도 있으면 총합은 빈칸이고 계산 가능한 값은 부분합에만 표시합니다.
- **보완근거**: 약물별 기본 방법, 실제 적용 방법, 기준약물, 계산에 쓴 용량·계수·환산값, 출처와 원본 위치입니다. 필터에서 처리=보완을 선택하면 보완한 항목만 볼 수 있습니다.

각 기본 방법을 먼저 적용합니다. 해당 계수가 없으면 CMD → MED → ED95 → DDD → GARDNER → WOODS → CPZ_FGA → CMD_DIRECT → CMD_INDIRECT 중 적용 가능한 첫 방법을 사용합니다. 기본 방법은 중복 적용하지 않습니다. 이 순서는 사용자가 선택한 프로그램 규칙이며 문헌이 검증한 우열 순서가 아닙니다. 결과는 혼합 지표로, 순수 CMD·MED 등의 결과와 구분합니다. 정책 버전은 `supplemented-1.0`이며 시트 머리글 메모와 `/version`에 남깁니다.

기준약물은 기본 방법을 따릅니다. 예를 들어 ED95의 빈 값을 보완할 때는 대체 방법에서도 RIS로 직접 환산한 계수를 사용합니다. OLZ·RIS·CPZ 기본 출력값을 그대로 섞거나 방법을 가로지르는 임의의 연결계수를 만들지 않습니다. 계수표는 수정하지 않습니다.

약물명 미확인, 잘못된 용량·단위, 성분 충돌, 날짜 오류, 중복 등 기존 확인 사유는 보완으로 해소하지 않습니다. 단위가 생략된 입력의 새로운 보완은 보류합니다. 주사제는 기존에 지원하는 제품·용량·간격만 사용하며, 경구 환산에 필요한 단일 대응용량이 없으면 다른 방법으로 우회하지 않습니다. DDD의 주사제 환산은 기존 제형별 규칙을 유지합니다. 주사제 근거에는 사용한 경구 대응용량 또는 활성성분 일일량과 관련 출처를 기록합니다.

날짜별 결과는 기존 분석이 선택한 동일 처방 행을 사용합니다. 일반 업로드, 한 줄 입력의 Excel 저장, 날짜별 Excel 결과에 적용됩니다. 상세 분석의 CSV ZIP 출력과 한 줄 화면의 순수 방법별 결과는 기존 형식입니다.

근거 문헌을 조합한 선례로 Hayes et al. (2021), [Greater than the Sum](https://doi.org/10.3389/fphar.2021.709349)이 있으나, 본 프로그램의 보완 순서나 혼합 지표를 검증한 연구는 아닙니다. 각 약물의 계수 출처는 보완근거에 따로 표시합니다. 환산되지 않은 값을 0으로 간주하지 않습니다. 인식된 비항정신병약의 0은 항정신병약 등가용량에 대한 기여값입니다.
