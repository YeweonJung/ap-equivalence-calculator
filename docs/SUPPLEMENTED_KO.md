# 보완 환산 결과

첫 두 시트에서 보완 방법별 계산안을 비교합니다. 기존 Results, MedicationResults, Review, AuditTrail은 그 뒤에 배치하며 원래 값과 구성을 유지합니다.

- **보완합계**: 환자·날짜·계산안별 총합, 사용 방법, 보완 방법을 보여줍니다. 한 계산안이 한 행이며 약물별 행은 없습니다. 미환산 항목이 하나라도 있으면 총합은 빈칸이고 계산 가능한 값은 부분합에만 표시합니다.
- **보완근거**: 각 계산안의 약물별 적용 방법·환산값, 계산 용량·계수, 출처와 원본 위치입니다. 첫 시트와 같은 환자·날짜·계산안으로 필터링할 수 있습니다.

각 기본 방법의 계산 가능한 값은 고정합니다. 계수가 없는 약물에 대해서만 다른 방법을 하나씩 적용해 계산안을 만듭니다. 예를 들어 CMD에서 paliperidone을 환산하지 못하면 CMD+MED, CMD+ED95, CMD+DDD, CMD+GARDNER를 각각 보여줍니다. 한 계산안에서 MED로 환산하지 못한 다른 약물을 DDD로 다시 보완하지 않습니다. 일부만 보완되면 해당 계산안은 미완료입니다.

보완 방법으로 적어도 한 약물을 새로 환산할 수 있는 계산안만 추가합니다. 기본 방법으로 모두 환산되거나 어떤 방법으로도 보완할 수 없으면 기본 방법 행을 한 번만 표시합니다. 모든 약물별 방법 조합을 생성하지 않습니다. 표시 순서 CMD·MED·ED95·DDD·GARDNER·WOODS·CPZ_FGA·CMD_DIRECT·CMD_INDIRECT는 임상적 우열을 의미하지 않습니다. 결과는 혼합 지표로 순수 방법 결과와 구분합니다. 정책 버전은 `supplemented-cases-2.0`이며 시트 머리글 메모와 `/version`에 남깁니다.

기준약물은 기본 방법을 따릅니다. 예를 들어 ED95의 빈 값을 보완할 때는 대체 방법에서도 RIS로 직접 환산한 계수를 사용합니다. OLZ·RIS·CPZ 기본 출력값을 그대로 섞거나 방법을 가로지르는 임의의 연결계수를 만들지 않습니다. 계수표는 수정하지 않습니다.

약물명 미확인, 잘못된 용량·단위, 성분 충돌, 날짜 오류, 중복 등 기존 확인 사유는 보완으로 해소하지 않습니다. 단위가 생략된 입력의 새로운 보완은 보류합니다. 주사제는 기존에 지원하는 제품·용량·간격만 사용합니다. 단일 경구 대응용량이 없으면 경구 계수로 환산하지 않으며, 제형별 DDD가 검증된 경우에만 별도의 DDD 보완 계산안을 제공합니다. 이때 경구 대응용량 누락과 DDD 적용 사실을 근거에 표시합니다. 주사제 근거에는 사용한 경구 대응용량 또는 활성성분 일일량과 관련 출처를 기록합니다.

날짜별 결과는 기존 분석이 선택한 동일 처방 행을 사용합니다. 일반 업로드, 한 줄 입력의 Excel 저장, 날짜별 Excel 결과와 한 줄 바로보기에 같은 계산안 규칙을 적용합니다. 화면에서는 계산안별 총합이 먼저 나오고 약물별 근거는 펼쳐서 볼 수 있습니다. 기존 방법별 결과도 접힌 영역에 보존합니다. 상세 분석의 CSV ZIP 출력은 기존 형식입니다. Excel 행 한도를 초과하면 일부 계산안을 생략하는 대신 파일을 나누도록 안내합니다.

근거 문헌을 조합한 선례로 Hayes et al. (2021), [Greater than the Sum](https://doi.org/10.3389/fphar.2021.709349)이 있으나, 본 프로그램의 보완 순서나 혼합 지표를 검증한 연구는 아닙니다. 각 약물의 계수 출처는 보완근거에 따로 표시합니다. 환산되지 않은 값을 0으로 간주하지 않습니다. 인식된 비항정신병약의 0은 항정신병약 등가용량에 대한 기여값입니다.
