# 환자·처방일별 환산 규칙 v2.0

메인 CSV·Excel 업로드는 환자 ID와 처방일이 같은 행들만 묶어 환산합니다. 처방 기간이 겹치더라도 다른 날짜의 처방은 가져오지 않습니다. 같은 날 서로 다른 함량·성분의 정상 처방은 각각 환산 후 합산합니다. 처방일수는 선택 입력이며 합산이나 복용기간 추정에 사용하지 않습니다. reference_date, MRI 날짜 등 별도 기준일 열도 메인 업로드의 날짜 묶음을 변경하지 않습니다.

예: 환자 001의 9월 1일 30일분 처방과 9월 15일 처방은 각각 별도 결과입니다. 9월 15일에는 9월 1일의 잔여 처방을 더하지 않습니다. 이는 처방일별 기록의 일일용량 합계이며 실제 복용량을 확인한 값이 아닙니다.

## 입력

필수 열은 환자 ID, 처방일, 약물명(성분·함량·제형), 하루 정/캡슐 수입니다. 제품명과 처방일수는 선택 사항입니다. SNU 열 HID, PRESCR_DATE, DRUG, TABS_PER_DAY 및 기존 한국어·영어 별칭을 지원합니다. ID의 앞자리 0, 원문, 원본 시트·행 번호를 보존합니다. 여러 시트에서도 같은 환자·같은 날짜를 묶습니다.

경구 고형제의 일일용량은 단위 함량 × 하루 정/캡슐 수입니다. 환산법별 기준약물을 유지하며 서로 다른 방법의 결과는 더하지 않습니다.

## 검토 항목

완전히 동일한 행 반복, 미확인 약물, 성분·함량·제형 충돌, 주사제·필요시·변동 복용·액제, 잘못된 하루 정 수는 자동 확정하지 않습니다. 해당 날짜에 미해결 약물이나 환산계수 누락이 있으면 해당 방법의 합계는 빈칸입니다. 같은 날 같은 성분이라는 이유만으로는 합계를 막지 않습니다.

날짜가 잘못된 행은 Review에 남기고, 어느 날짜에 속하는지 알 수 없으므로 해당 환자의 합계를 검토 대상으로 둡니다. 유효한 환자·처방일 조합이 전혀 없으면 오류로 안내합니다. ID 없는 행은 임의로 다른 환자에게 합치지 않습니다. 빈칸은 0이 아닙니다.

## 결과

AP_equivalence_results.xlsx의 Results는 환자·처방일당 한 행이며 방법별 합계가 가로 열입니다. MedicationResults는 약물별 상세와 원본 위치를, Review는 확인이 필요한 행을 제공합니다. 합산 규칙과 버전은 통합문서 속성에 보관합니다.

상세 CSV API의 지정 날짜는 그 날짜에 발행된 처방만 선택합니다. 이전 review/replace 요청값으로 기간 합산을 다시 켤 수 없습니다. 내부 이전 기간분석 함수는 호환성을 위해 남아 있으나 업로드 경로에서 사용하지 않습니다.

원본은 변경하거나 영구 저장하지 않습니다. 이 업로드 경로는 AI·피드백·DB에 처방자료를 보내지 않습니다. 공개 배포 검증에는 합성 자료만 사용합니다.
