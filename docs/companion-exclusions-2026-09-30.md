# 병용약물 배제 목록

사용자가 제공한 `결과표_병용약물포함.xlsx`의 `mean!A3:A56`과 색상 순서 설명을 기준으로 54개 성분을 등록했다. 원본 파일은 변경하지 않았다. 원본의 통계값과 수식은 환산에 사용하지 않는다.

| 원본 분류 | 범위 | 성분 수 | 처리 |
|---|---|---:|---|
| 항정신병약 | A3:A17 | 15 | 기존 환산 규칙 유지. 계수가 없으면 확인 필요 |
| 기분조절제 | A18:A22 | 5 | 환산 합계에 0 기여 |
| 항우울제 | A23:A38 | 16 | 환산 합계에 0 기여 |
| 항불안제 | A39:A50 | 12 | 환산 합계에 0 기여 |
| 각성제 | A51:A53 | 3 | 환산 합계에 0 기여 |
| 부작용처리약 | A54:A56 | 3 | 환산 합계에 0 기여 |

`lookup/companion_medications.json`은 원본 성분명, 셀, 색상 기반 분류, 적용 분류, 파일 SHA-256을 보존한다. 기존 항우울제 목록과 합쳐 사용하므로 기존 인식 표기도 유지된다. 첨부파일에는 영문 성분명이 있으므로 새 상품명이나 한글 표기를 추측해서 추가하지 않았다.

Trazodone은 원본 항불안제 묶음에 있지만 적용 분류는 항우울제로 유지한다. Naltrexone은 원본 각성제 묶음에 있지만 적용 분류는 opioid_antagonist로 구분한다. 분류 확인 출처는 목록 파일의 DailyMed 제품설명서 링크에 기록했다. 원본의 나머지 분류는 이 프로젝트의 기능별 묶음으로 사용하며 규제상 향정신성의약품 분류를 뜻하지 않는다.

빠른 입력, 구조화 입력, CSV/Excel, 처방일별 합산에 같은 배제 집합을 사용한다. 원문과 입력 용량은 보존하고, 환산값만 0으로 처리한다. AuditTrail에 적용 분류와 배제 근거·원본 셀을 남긴다. 약물명 오타·미확인 성분·복합 성분 충돌과 항정신병약의 계수 누락은 Review 대상으로 유지한다. 다른 처방일의 약물은 이월하지 않는다.

사용자의 추가 요청에 따라 배제된 병용약도 Review에 표시한다. 인식 성분, 한글 약물 분류, 계산 처리 `배제 완료`, 항정신병약 환산 기여값 `0`을 기재한다. 이 행은 배제 내역을 보여주는 정보이며 계산 오류나 계산 보류를 뜻하지 않는다. 미확인 약물의 Review 행은 여전히 환산값이 비어 있으며 합계 보류 규칙을 유지한다.
