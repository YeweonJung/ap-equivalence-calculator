# 두 글자 등록 약물명 수동 후보 보완

제보 입력 `할리l 2mg BID`의 의도한 이름은 사용자가 확인한 `할돌`이다.
정확한 할돌은 기존 파서가 인식하지만 기존 후보 사전은 3글자 이상만 포함했다.

새 `services/short_alias_suggestions.py`는 기존 후보가 없을 때만 실행된다.
두 한글 음절 또는 두 한글 음절 뒤 영문 한 글자만 허용하고, 첫 음절이 같은
등록된 두 글자 별칭을 조회한다. 순수 한글은 NFD 자모 거리 1 이하로 제한한다.
혼합 입력은 원문 기준 최대 두 편집을 허용하며 영문을 한글로 자동 번역하지 않는다.
후보가 3개를 넘으면 제안하지 않는다. 낮은 유사도 표시와 사용자 선택을 요구한다.
이름별 하드코딩은 없으며 `할리l`에 대한 후보는 `할돌 2mg BID`이다.
선택 전 환산은 없고 선택 후 기존 파서로 다시 계산한다.

진단 과정에서 순수 한글 한 음절 치환을 넓게 허용하면 스트레스 사례 `리스`에
리튬을 제안하여, 순수 한글의 자모 조건을 추가했다. 최종 규칙으로 기존 스트레스
1,388건의 후보 변화는 0건이다. 이 자료를 보며 규칙을 보완했으므로 독립 평가나
일반화 정확도 개선의 증거로 해석하지 않는다. 기존 고정 실험과 모델은 보존했다.
혼합 입력에 대한 독립 평가가 충분하지 않아 수동 확인용으로만 제공한다.

API, Excel 미확정 기록, 용량·빈도 보존, 범위 밖 입력 거절 및 rollback을 테스트한다.
환산표·환산 공식·기존 파서·LR 모델은 변경하지 않는다.
