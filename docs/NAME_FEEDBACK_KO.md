# 약물명 수정 기록 수집

한 줄 확인에서 후보를 선택하거나 정확한 이름을 직접 입력할 때, 사용자가
개인정보가 없는 약물명임을 확인하고 기록 제공에 동의한 경우에만 저장한다.
동의하지 않아도 계산은 가능하다. 파일 업로드의 처방 전체를 수집하지 않는다.
직접 수정은 계산에 바로 반영되지만 기록 대상은 사전에 등록된 정확한 이름뿐이다.
미등록 이름은 정답으로 검증할 수 없어 기록하지 않는다.

저장: 이름 토큰, 선택 별칭·성분, 제시 후보, 선택/직접 수정 구분, 검색·사전 버전,
무작위 이벤트 ID, 제출 시간, 사용자 확인 상태와 학습 동의 여부. 용량, 빈도, 환자 ID, IP, 원본 처방은
이 테이블에 저장하지 않는다. 서비스 제공자의 기본 접속 로그는 별도다.
단어 형태 필터는 사람 이름과 약물명을 완전히 구별할 수 없으므로 사용자 확인을 요구한다.
15분 유효 서명 토큰과 같은 사이트 요청 검사, 이벤트 중복 방지, 시간당 전체 500건
제한을 적용한다. 익명 사용자를 식별하지 않으므로 반복 클릭 수는 독립 사용자 수가 아니다.
2026-09-29부터 별도의 학습 동의를 한 수정은 eligible_for_training=true로 저장한다.
등록 약물명과 현재 사전 버전을 검증하고, 최근 180일·최대 5,000건에서 사례 기반 모델을 자동 구성한다.
이 모델은 같은 이름의 수정 사례를 집계한다. 서로 다른 성분·제품으로 수정된 기록이 충돌하면 추천하지 않는다.
사례 수는 정확도나 독립 사용자 수가 아니다. 같은 오타의 후보 추천만 개선하며 자동 약물 확정이나 환산 계수 변경은 하지 않는다.
대형 언어 모델의 가중치 재훈련이나 보지 못한 오타에 대한 일반화를 뜻하지 않는다.
과거 검토용 기록은 학습 동의가 없으므로 그대로 제외한다. 저장한 서버는 즉시 갱신하고 다른 서버 프로세스는 최대 60초 후 갱신한다.
FEEDBACK_LEARNING_ENABLED=0으로 즉시 비활성화할 수 있다. DB 오류는 추천을 생략하고 계산을 유지한다.

## 저장소

Render 환경변수에 `FEEDBACK_DATABASE_URL`(Neon PostgreSQL 연결 URL, SSL 필수),
`FEEDBACK_SIGNING_KEY`(32바이트 이상 난수)를 설정한다. 비밀값은 Git에 넣지 않는다.
Neon Free만 사용하고 결제수단/유료 플랜을 추가하지 않는다. 무료 사용량을 초과하거나
DB가 중단되면 저장 실패를 표시하고 계산은 계속한다. 영구 무료를 보장하는 것은 아니다.
Render의 30일 만료 무료 Postgres나 서비스 임시 디스크는 운영 기록 저장에 사용하지 않는다.
환경변수가 없으면 수집 동의 UI를 숨기고 수집 비활성 상태를 표시한다.
`/version`의 feedback_configured는 설정 유무이며 DB 연결 건강 상태를 보장하지 않는다.

로컬 테스트 전용으로 FEEDBACK_SQLITE_PATH를 사용할 수 있으나 RENDER 환경에서는 거절한다.
PostgreSQL 테이블은 최초 동의 제출 시 만들어지며 앱 재배포와 독립적으로 유지된다.
180일 지난 기록은 다음 저장 또는 검토 내보내기 시 삭제한다. 예약 삭제 작업은 없다.

## 검토 내보내기

DB 환경변수가 있는 신뢰할 수 있는 로컬 환경에서
`python scripts/export_feedback_review.py --output <비공개 경로>/pending.jsonl`로 내보낸다.
공개 조회 API는 없다. 잘못된 선택·개인정보·중복·테스트 기록을 제거하고 검토자가
정답을 확인한 이후에만 별도의 학습 데이터로 편입한다. 원래 고정 평가셋은 보존하며
향후 재학습 시 사용자/오타 그룹 단위 중복 유출을 막고 독립 평가 후 배포한다.
