# 결과 상태 코드와 오류 전용 Review — 2026-10-23

사용자 요청에 따라 검토필요는 확인된 입력 오류만 뜻한다. 환산 불가나 인식 실패 자체를 오류로 판정하지 않는다.

| 코드 | 뜻 | 처리 |
|---|---|---|
| a | 미환산 | 일부 또는 전체 방법의 환산계수·제형별 근거 없음 |
| b | 인식불가 | 등록 약물명으로 인식하지 못함 |
| c | 정보부족 | 용량·단위·빈도·간격·ID 부족 또는 입력 가정 |
| d | 중복·일정 불확실 | 중복 후보 또는 불확실한 처방 일정 |
| e | 환산대상 아님 | 정확히 인식된 제외 약물, AP 환산 기여값 0 |
| x | 오류 · 검토필요 | 확인된 성분·함량·단위 충돌, 잘못된 숫자·날짜 등 |

코드가 없으면 정상이다. 여러 상태는 세미콜론으로 병기한다. Review에는 x만 들어간다. 나머지 항목도 약물별 결과와 AuditTrail에 남는다. 약물 프레임을 만들 수 없었던 ID/열 누락도 AuditTrail에 보존한다. 결과 파일의 코드안내 시트와 홈페이지에 동일한 코드 정의를 표시한다.

보완합계, 보완근거, Results, MedicationResults, AuditTrail에 상태코드·상태설명·검토필요를 추가한다. 기존 needs_review는 계산 안전성 플래그로 유지하며, 검토 목록은 별도 review_required로 결정한다. AuditTrail에서 기존 플래그의 표시명은 입력 가정·제한으로 바꾼다.

환산계수와 계산식, 자동 확정 및 합산 제한은 변경하지 않는다. 인식하지 못한 약물이나 정보가 부족한 약물을 0으로 간주하지 않는다. 해당 방법의 전체 합계는 빈칸으로 유지하고 계산된 부분합과 미환산 개수를 별도로 표시한다. 기존에 허용된 mg/QD 가정은 c로 드러내되 계산 방식은 그대로 둔다. 지원 범위를 초과한 양의 정 수는 실제 처방 오류라고 단정하지 않고 c로 표시한다.

검증: 정상·부분 계수·전체 미환산·미인식·누락·음수·빈도 충돌·주사 간격 오류·날짜 오류·성분 불일치·중복 사례를 일반 업로드, 날짜별 업로드와 한 줄 계산/Excel 저장에서 확인한다. 배포 버전은 2026.10.23-status-codes이다.
