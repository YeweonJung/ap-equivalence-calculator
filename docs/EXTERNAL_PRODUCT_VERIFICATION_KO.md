# 추가 공개 제품 표기 검증

2026-10-19. 기존 MIMIC-IV 데모 검증에 더해 두 공개 자료에서 제품 표기와 환산 대상이 아닌 약물의 처리를 점검했다. 화면에 옵션이나 분석 결과를 추가하지 않았으며 Excel은 기존 6개 시트를 유지한다.

## 자료와 시험 조건

- [openFDA NDC](https://open.fda.gov/apis/drug/ndc/): 항정신병약 성분 13개에 대해 성분당 최대 100개를 조회하여 1,120개 제품 기록을 받았다. 비처방·동종요법 기록 2개를 제외하고 이름·성분별 함량·제형·경로가 같은 표기를 합쳐 250개를 선택했다. 전체 NDC 제품을 빠짐없이 검사한 것은 아니다.
- 이 중 경구·설하 단일 성분 고형제 190개에는 **1회 1단위, 하루 1회라는 합성 조건**을 붙였다. NDC의 제품 함량은 실제 처방 용량이나 복용 횟수가 아니다. 조합제, 주사제, 경피제, 농도만 있는 액제 등 60개는 자동 환산을 보류해야 하는 사례다. 액제 8개에는 같은 농도를 `mg/1 mL`로 다시 쓴 시험을 추가했다.
- [Synthea 공개 표본](https://synthetichealth.github.io/synthea/): 공식 April 2020 CSV ZIP의 약물 42,989행에서 고유 제품 설명 134개를 추렸다. 선택한 13개 항정신병약 성분에 해당하는 설명은 없었다. 따라서 항정신병약 환산값을 잘못 만들지 않는지 확인하는 음성 대조 입력으로 사용했다. 합성 환자 자료이며 실제 환자 자료가 아니다.
- 총 392개: 정상 일일 함량 190개, 자동 환산 보류 68개, 비대상·미확인 제품 134개. 시험 ID는 별도로 만들었고 환자 ID, 날짜, 진단 등은 입력하지 않았다.

원본 다운로드 주소와 SHA-256, 선택한 제품 NDC, 시험 조건과 기대값은 `data/evaluation/external_products.json`에 기록했다. NDC 등록 자체가 FDA 승인이나 정보의 정확성을 보증하지 않는다. 이 검증은 입력 해석·보류 처리·Excel 일관성에 대한 개발 검사이며 임상 환산계수의 타당성 평가가 아니다.

## 발견과 수정

수정 전 381/392개가 기준을 만족했다. 경피 아세나핀 3개가 경구 용량으로 계산되고, 분모를 명시한 액제 농도 8개가 1회 용량처럼 처리되는 오류를 재현했다. 다음과 같이 고쳤다.

- `TRANSDERMAL`, `patch`, `패치`는 경피제로 유지하고, 제형별 근거가 없어 환산을 보류한다. 날짜가 있는 업로드에서도 정제 표기가 섞여 있다고 경구 계수를 적용하지 않는다.
- `mg/1 mL`, `mg per 1 mL`, `mg in 1 mL` 등의 농도를 1회 투여량으로 사용하지 않는다. `per`가 기존 약물 약칭과 겹쳐 입력이 잘리는 경우도 막았다. 날짜가 있는 파일도 같은 원칙을 적용한다.
- `INTRAVENOUS` 경로가 뒤따르는 숫자 빈도 때문에 잘려 경구 처방으로 처리되지 않도록 보강했다.
- 검증된 주사 제품의 주사기 총함량 표기(`Abilify Maintena 300mg/1.5mL q4w`)와 정상적인 경구·설하 처리는 유지한다.

수정 후 로컬 계산은 392/392개를 만족했고, 같은 CSV를 업로드한 Excel과 API 사이의 약물명·일일 mg·경로·검토 여부 차이는 0개였다. 추가 회귀 검사는 혼합 입력, 날짜별 업로드 및 기존 주사제 처리를 포함한다.

## 재현과 배포 확인

```text
python scripts/verify_external_products.py --output output/external-local/report.json
python scripts/verify_external_products.py --base https://ap-equivalence-calculator.onrender.com --commit TARGET_COMMIT --output output/external-live/report.json
```

도구는 `/version`의 커밋이 지정한 값과 같을 때만 실제 배포를 검사한다. 입력 CSV, 반환 Excel, 통과 수와 실패 이유를 같은 출력 폴더에 저장한다. 실제 배포에는 시험용 제품 표기만 보낸다. 반환 시트는 `보완합계`, `보완근거`, `Results`, `MedicationResults`, `Review`, `AuditTrail`이다.
