# 국내 공개 의약품 표기 검증

2026-10-19. 한국보건산업진흥원이 공개한 [심평원 2026-04-01 약제급여목록](https://www.khidi.or.kr/board/view?linkId=48942231&menuId=MENU01869)의 원본 Excel을 사용했다. 현재 유통·급여 상태를 판정하는 자료가 아니라 해당 날짜의 공개 제품 표기를 검증하는 표본이다.

- 원본: [공개 Excel](https://www.khidi.or.kr/fileDownload?fileDownType=C&fileId=1&paramMenuId=MENU01869&titleId=526047)
- SHA-256: `0c36ef6e516914a0dcb31c54384b5c25a23e6e70eb69c6066a2888760006ef13`
- 원본 성분명에서 환산계수표의 항정신병약 성분과 일치하는 321개 제품을 선택했다. 경구 제품 303개, 주사제 18개다. 제품코드는 앞자리 0을 포함해 문자열로 보존한다.
- 전체 제품명과 고유하게 식별되는 짧은 상품명 등 636개 표기를 검사한다. 경구 제품은 한 단위 QD, 지원하는 지속형 주사제는 명시적인 유지요법 간격을 붙인 **합성 시험 조건**이다. 심평원 목록에 실제 처방 빈도나 환자 정보가 있다는 뜻이 아니다.

## 발견과 수정

상품명과 포장정보에 함량이 반복되는 표기를 별도 투여량으로 읽거나, 수출명이 붙은 한 제품을 두 약물로 자르는 문제가 있었다. 일부 한글 상품명을 식별하지 못하고, `페리돌주`의 주사 경로도 놓쳤다. 또한 주사제의 염·수화물 함량과 주성분 함량을 구분해야 했다.

상품명에 함량이 있더라도 별도 빈도 열의 BID 또는 주사 간격을 반영한다. 상품명과 별도 용량 열이 충돌하거나 빈도가 불명확하면 확인 대상으로 남긴다. 일반적인 제품 출처 설명은 펼친 상세 근거에 두고 첫 화면에는 최종 합계와 필요한 확인 사항만 표시한다.

`lookup/korean_public_products.json`에는 원본 행, 제품코드, 전체 상품명, 성분명, 투여경로, 주성분 함량, 정확한 이름 별칭을 저장했다. **등록된 전체 제품 또는 고유한 별칭과 정확히 일치할 때만** 제품 함량 중복을 정리한다. 여러 함량에 걸쳐 중복되는 짧은 이름은 등록하지 않는다. 원문과 출처를 결과에 남기며, 추가로 적힌 용량·경로·간격·PRN 등의 조건은 삭제하지 않는다. 알 수 없는 이름을 유사한 상품명으로 자동 확정하지 않는다.

메인테나 400mg은 수화물 416mg과 구분한다. [식약처 허가정보](https://nedrug.mfds.go.kr/pbp/CCBBB01/getItemDetailCache?cacheSeq=201508423aupdateTs2026-09-17+20%3A04%3A59.0b)의 아리피프라졸 기준 함량과 대조했다. 서스티나 156mg 표기의 활성 팔리페리돈은 100mg이며, 국내 트린자 포장에 적힌 410.3mg 표기는 공개 목록의 팔리페리돈 263mg으로 해석한다. 제품별 질량·경구 대응량·DDD 환산계수 자체는 기존 검증 규칙을 유지한다. 단기 할로페리돌 주사 2개는 지속형 제품으로 간주하지 않고 환산을 보류한다.

첫 시트의 순차 보완과 두 번째 시트의 방법별 비교는 [기준 방법 안내](SUPPLEMENTED_KO.md)를 따른다. 국내 표기 시험에서도 일반 업로드와 날짜별 업로드를 함께 검사하고, 실제 배포와 로컬의 6개 시트 전체 값을 비교한다. 이것은 입력 처리 개발 검증이며 환산계수의 임상적 타당성 연구가 아니다.

## 재현

```text
python scripts/verify_korean_products.py --source hira_20260401.xlsx --output output/korean-local/report.json
python scripts/verify_korean_products.py --base https://ap-equivalence-calculator.onrender.com --commit TARGET_COMMIT --output output/korean-live/report.json
```

`--source`를 주면 원본 해시와 모든 선택 행의 제품코드·상품명·성분·경로를 대조한다. 검사 결과, 합성 CSV, 반환 Excel을 출력 폴더에 저장한다. 실제 서비스에는 공개 제품 표기와 새 시험 ID만 전송한다.
