날짜별 처방 분석

여러 처방일이 반복되는 CSV에서 기준일의 항정신병약물 용량을 계산합니다.

{% if detected_notice %}
처방일 열이 있어 종단 자료로 인식했습니다. 날짜가 다른 처방을 합산하지 않도록 이 화면으로 전환했습니다. 아래에서 CSV를 다시 선택하고 기준일을 지정하세요. Excel 자료는 분석할 시트를 CSV로 저장해 주세요.

1. 처방 CSV와 열 연결

15MB·100,000행 이하, 첫 행은 열 이름. UTF-8·CP949 지원. 이름·생년월일은 분석에 사용하지 않습니다. 업로드 전 가명 ID를 사용하고 불필요한 개인정보 열을 제거하세요.

파일을 선택하면 열을 자동으로 연결합니다.

2. 기준일

열 이름: patient_id, reference_date. 날짜: YYYY-MM-DD. 같은 피험자에게 여러 기준일을 지정할 수 있습니다.

3. 중첩 처방 규칙

대체 가정은 같은 성분·제형의 확인 가능한 경구약에만 적용합니다. 새 처방일부터 이전 처방을 끝내며, 원래 기간과 조정 사유를 함께 제공합니다. 같은 날 여러 처방·주사제·함량 충돌은 자동 합산하지 않습니다.

결과 읽기

Results에서 환자·기준일별 합계를 확인하세요. MedicationResults는 약물별 상세, Review는 확인이 필요한 처방입니다. 빈칸은 0이 아닙니다. 결과는 처방 기록상 추정 용량입니다.

검토가 필요한 기록
  • 일수 0·누락·잘못된 날짜, 약물명·함량·제형 충돌
  • 같은 날 여러 함량이나 동일 행 반복: 분할 처방인지 중복인지 확인
  • 주사제·필요시 복용·액제: 별도 투약 정보 확인
  • 해당 날짜에 처방이 없으면 no_record: 비복용 0으로 해석하지 않음

업로드 파일은 요청 처리에 사용하고 영구 저장하지 않습니다. 이 기능은 처방자료를 데이터베이스·피드백·AI 서비스에 저장하거나 보내지 않습니다.
