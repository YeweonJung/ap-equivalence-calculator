날짜별 처방 분석

처방 파일(CSV·Excel)을 환자 ID와 처방일별로 묶어 총 환산 용량을 계산합니다.

{% if detected_notice %}
처방일 열이 있는 처방 원자료라서 이 화면으로 옮겼습니다. 파일을 다시 고르고, 아래 칸마다 맞는 열을 고른 뒤 계산하세요.
{% endif %}

1. 처방 파일과 열 연결

15MB·100,000행 이하, 첫 행은 열 이름. UTF-8·CP949 지원. 이름·생년월일은 분석에 사용하지 않습니다. 업로드 전 가명 ID를 사용하고 불필요한 개인정보 열을 제거하세요. Excel은 처방 시트 하나만 두세요. 보험 약품코드 열이 있으면 연결하세요. 성분과 함량을 약품명 대신 코드로 맞춥니다.

파일을 고르면 아래 칸마다 파일의 열 목록이 나옵니다. 칸마다 맞는 열을 고르세요.

2. 환자·처방일별 합산

같은 환자의 같은 처방일에 받은 약들만 합산합니다. 다른 날짜의 처방은 남은 처방일수나 기간 중첩과 관계없이 포함하지 않습니다. 처방일수 열은 선택 사항입니다.

기준 방법으로 계산하고, 값이 없는 약만 정해진 순서로 다른 환산표에서 채웁니다.

결과 읽기

Results에서 환자·처방일별 합계를 확인하세요. MedicationResults는 약물별 상세, Review는 확인이 필요한 처방, AuditTrail은 모든 원본 처방의 처리 기록입니다. 빈칸은 0이 아닙니다. 결과는 처방 기록상 추정 용량입니다.

검토가 필요한 기록
  • 잘못된 날짜, 약물명·함량·제형 충돌
  • 완전히 동일한 행 반복: 중복 여부 확인
  • 주사제·필요시 복용·액제: 별도 투약 정보 확인
  • 해당 날짜에 처방이 없으면 no_record: 비복용 0으로 해석하지 않음

업로드 파일은 요청 처리에 사용하고 영구 저장하지 않습니다. 이 기능은 처방자료를 데이터베이스·피드백·AI 서비스에 저장하거나 보내지 않습니다.
